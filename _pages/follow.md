You can follow new articles with an **RSS reader**. It collects updates from websites you choose, so you do not need to keep checking each site.

Copy this feed address into your reader’s **Add feed** or **Subscribe** field:

```text
https://ahmelkholy.github.io/feed.xml
```

[Open the RSS feed](/feed.xml)

The feed is an XML file intended for subscription software. Seeing XML when you open it in a browser is normal; it is not an empty or broken page.

Prefer to browse? [Read all articles](/articles/) or visit [YouTube](https://www.youtube.com/@ahmelkholy).
