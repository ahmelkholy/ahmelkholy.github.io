Это документация для автора и пример оформления, а не опубликованная статья или описание инженерного достижения. Для обычной записи достаточно файла Markdown и короткого заголовка YAML с `lang: ru`.

## Текст и код

Задайте `title`, `date`, `lang` и при необходимости `tags`. Перевод на другие языки не обязателен.

```python
voltage = 230
current = 5
print(voltage * current)
```

## Переводы и изображения

Настоящим переводам задайте одинаковый `translation_key`. Ссылки появятся только на существующие опубликованные страницы. Для изображений добавляйте содержательное описание в атрибуте `alt`.
